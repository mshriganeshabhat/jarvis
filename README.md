🤖 Python Mini JARVIS

A simple interactive assistant built with Python.

✨ Features

- Displays the current time
- Tells random programming jokes
- Gives motivational messages
- Interactive command-line menu

🛠️ Technologies

- Python
- datetime
- random

▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Run:

python jarvis.py

🎯 Goal

My beginner Python project to practice programming and build a personal assistant.
